# Entre idiomas

Una primera versión funcional de tu web para mantener inglés y alemán.

## Abrirla mañana en VS Code

1. Descomprimí el ZIP en una carpeta nueva para conservar tu versión anterior.
2. Abrí esa carpeta en VS Code.
3. Abrí `index.html` con tu navegador, o usá Live Server si ya lo tenés instalado.
4. Para usarla en celular o tablet desde tu PC, necesitás servirla en tu red local o publicarla. Abrirla en la PC no la hace accesible automáticamente desde otros dispositivos.

No requiere instalar paquetes ni ejecutar un proceso de compilación.

## Qué archivo estudiar

- `index.html`: estructura, navegación y ventana de práctica.
- `styles.css`: diseño y adaptación a pantallas pequeñas.
- `script.js`: contenido, eventos, ejercicios, metas y guardado.

Los tres archivos incluyen comentarios. Los archivos reemplazan la versión inicial completa; no pegues su contenido al final de los archivos anteriores.

## Incluye

- Tres unidades por idioma, con teoría y cuatro preguntas por unidad (24 ejercicios en total).
- Consejos con contexto y registro, guardables para repasar.
- Sesiones con consejo inicial, teoría, respuestas y explicación inmediata.
- Repaso de errores, puntos, medallas y recompensa personal a las 20 sesiones.
- Diseño para celular, tablet y computadora, navegación por teclado y ventana accesible.

## Cómo se mide el avance

Una sesión cuenta después de responder todos sus ejercicios y abrir el resultado. Cerrar antes no suma una sesión. Repetir unidades cuenta para la constancia; cada pregunta diferente suma 10 puntos solo la primera vez que la respondés bien. Las unidades completadas no son una certificación de dominio ni una evaluación de nivel.

El progreso se guarda en localStorage en este navegador y en esta dirección. No hay cuentas, servidor ni sincronización entre dispositivos. Cambiar de navegador/dirección, borrar sus datos o usar modo privado puede hacer que no encuentres el progreso. Algunas configuraciones restringen localStorage al abrir archivos directamente; en ese caso, usá un servidor local.

## Límites de esta versión

El contenido es un banco fijo de repaso intermedio/avanzado, no un curso completo ni una prueba CEFR. Las frases son expresiones habituales, no tendencias verificadas en tiempo real. No se incluyeron reconocimiento de voz, corrección automática de texto libre, IA ni premios reales entregados por la web. La recompensa personal es un objetivo que elegís y cumplís vos.

## Para aprender con un cambio pequeño

Buscá `--violeta` en CSS y cambiá su color. Después agregá un consejo al array `consejos` de inglés o alemán en JavaScript siguiendo el formato de los otros. Guardá y recargá para ver el resultado.
